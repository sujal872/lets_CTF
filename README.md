# lets_CTF 🚩

Complete cybersecurity prep vault — pentest methodology, Jeopardy-style CTF domain guides, and quick-reference cheat-sheets. Built while grinding TryHackMe & HackTheBox labs and prepping for SOC Analyst (L1) roles.

## 📂 What's Inside

| PDF | What it covers |
|---|---|
| **Web_Network_Pentest_Methodology_Roadmap.pdf** | Full attacker methodology — Recon → Scanning → Enumeration → Exploitation → Post-Exploitation → Privilege Escalation → Firewall Evasion. Includes port-by-port breakdown (FTP, SMTP, DNS, HTTP/S, POP3/IMAP, MySQL) with tools & commands for each phase. |
| **Jeopardy_CTF_Complete_Domain_Guide.pdf** | Domain-wise CTF guide — Web Security, OSINT, Digital Forensics, Cryptography, Networking, AI Security. Each domain has approach checklist, tool commands, and a real past-CTF example (picoCTF, DEF CON DFIR, etc.). |
| **Default_Credentials_Cheatsheet_PortWise.pdf** | Default/weak username-password combos organized port-by-port (21, 25, 53, 80/443, 110/143/993/995, 3306) + a universal "try-first" master list. |

## 🎯 Why this repo

Most CTF/pentest resources are scattered across blogs, Discord pins, and random PDFs. This repo is my personal, structured, colour-coded version — built as I study for TryHackMe SOC Level 1 / SIEM paths and prep for real Jeopardy-style CTFs.

## 🛠 How I use these

1. Before a CTF/lab — skim the relevant domain section for a quick tools/commands refresh
2. Stuck mid-challenge — jump to the "first thing to try" checklist for that category
3. Post-CTF — add new techniques/writeups I learned back into these notes

## ⚠️ Disclaimer

All content here is for **authorized environments only** — CTFs, TryHackMe, HackTheBox, personal labs, or engagements with explicit written permission. Do not use any technique/credential list against systems you don't own or have permission to test.
